Tinker's Eppie Skin:

	I have been using Eppie for quite a while with never a problem. I chose to make the buttons differant colours because my eyesight
is not so good.  I also find a bland user interface BORING!.  If youu can make stuff more colourful, do it!
	Here's a tip.  If you use WindowBlinds, you can use Eppie as well.  The trick is to remove (or comment out) the 'border' and 'button'
lines from the skin definition.  Removing the 'border' lines is enough to make this work, but take out the 'button' lines too... just in case.
WindowBlinds runs faster with FAR better compatability.  The 'Custom Color Dialog' window is my usual test. Try it.  This works with versions
1.xx and 2.xx of WindowBlinds.
	Downsides to this 'trick' are that WindowBlinds does NOT display the preview well (the borders are messed up) and SkinStudio will
NOT allow you to edit the skin.  No big deal in the day to day scheme of things.
	Also try out WindowsMakeUp (found on Vurtual Plastic) Which allows you to (with difficulty) make the 'OK, Cancel, etc.' buttons
differant colours too.  This program is compatible with WindowBlinds too, IF you start it first (I start WindowsMakeUp as a 'service' and
WindowBlinds in the StartUp folder.

	Have fun:
