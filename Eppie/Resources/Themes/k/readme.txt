
 *_up -> button up
 *_dw -> button down (pressed)
 *_ds -> button disabled

 la barre de titre active doit avoir une hauteur de '17' (px ??)
 (Propriétés de l'affichage > Apparence)

 dimensions des boutons :
  - width	: 15px
  - height	: 13px


 Amelioration du modele de couleur (grace au .3dc de kmr -- www.virtualplastic.net)
 Mais surtout des boutons plus beaux, quel mignon bouton close :)


Nota : il n'y a pas d'effet de transparence sur les boutons pour Eppie
       donc la couleur du coin haut droit doit etre la meme, que la fenetre
       ait ou non le focus (d'ou utilisation du gradient sur la barre de titre)

Nota : Eppie ne modifie pas tout les boutons, en effet dans le cas ou une
       application dispose d'un systeme de 'fenêtre interne' (comme Opera)
       lorsque l'on maximise une de ces fenetre interne, les boutons standards
       apparaissent en haut a droite, en dessous des boutons de l'application
       elle-meme.
       Heureusement, ce defaut deviens peu perceptible en utilisant 3DCC pour
       modifier les couleurs d'ombres des boutons 3D
      (mais les images par defaut demeurent, dans ce cas il faut surement
       modifier marlett.ttf pour y remedier)

 (l'effet est a peine discernable sur les captures)
